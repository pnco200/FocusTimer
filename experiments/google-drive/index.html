Isolated Google Drive proof

This diagnostic experiment creates disposable files in the chosen Google account. It does not sync Focus Timer history. Cross-client authorization is unproven until the official-client matrix is recorded.

Only drive.file is requested. Tokens stay in memory. Use a dedicated test account and the separate server origin described in the README. Do not paste tokens, secrets, real session data or private descriptions here.

Disconnected

1. Official client and account Revoke deliberately removes the application grant and forgets this token. Google may revoke the grant across official clients; record the observed result.
2. Discovery and deliberate bootstrap Root IDs are never selected automatically, even when a scan returns one candidate. Preparing another intent may create another dataset. Concurrent intents remain separate candidates; there is no singleton election or global manifest.
3. Retained publication and pagination

Inspect a complete root first. Preparation stores generated Drive IDs, synthetic protocol identities and exact bytes before content publication.

Prepare/publish additional segments between page clicks to observe concurrent listing. Publish at least five to force pagination where Google honors page size. Short/empty pages continue when a token exists. Full scans are capped at 100 pages per click and never claim completeness after that cap.
4. Bounded reads Use a known client A object from client B for the cross-client read test. Use a nonexistent ID and an inaccessible fixture for ambiguity tests. No operation mutates or deletes remote objects. To test changed bytes, modify a separate disposable fixture through Drive and reread it; never modify a protocol segment.
Local retained intents and evidence

Downloaded evidence includes test account permission IDs, public client IDs, Drive IDs, checksum metadata and opaque page tokens. Keep it private and redact identifiers before sharing. It contains no token or session bytes. Intent bytes remain in the dedicated experimental IndexedDB database until you deliberately clear that site's storage. Remote proof files remain until you deliberately remove them in Drive.
